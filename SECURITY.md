# Security policy

## Reporting a Vulnerability

Do not open a public GitHub issue. Submit a
[private security advisory](https://github.com/Rethunk-Tech/repo-ops/security/advisories/new)
with affected versions, reproduction, and impact. Acknowledgement within 48
hours; triage within 7 days for confirmed issues.

## Reporting a Code of Conduct Violation

Report privately — not via issues or security advisories. Contact a
[Rethunk-Tech organization owner](https://github.com/orgs/Rethunk-Tech/people)
or the **Contact maintainers** link on the
[repository home page](https://github.com/Rethunk-Tech/repo-ops).

## Supported versions

Only the latest minor receives security fixes.

## Scope

Local CLI, plus dependency and workflow issues.
